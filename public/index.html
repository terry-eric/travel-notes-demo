把旅手帖加入裝置

直接從桌面或主畫面開啟你的旅行。

電腦 · Edge / Chrome
使用網址列的安裝圖示，或在瀏覽器選單找到「安裝」選項。
Android · Chrome
開啟瀏覽器選單，選擇「安裝應用程式」或「加到主畫面」。
iPhone / iPad · Safari
按「分享」，選擇「加入主畫面」。若有「作為 Web App 開啟」，請開啟它。

首次在 App 開啟時可能需要重新登入。行程與 Google 地圖需要網路，登入後會同步同一份行程。
